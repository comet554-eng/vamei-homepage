# 《单板新手课》第14课 · 反脚滑行 · 方案

一句话：反脚时原来的后脚变前脚、看板尾方向；先推坡和落叶飘，再练换刃，最后连弯，左右练一样多。

## 片中说法 ↔ 出处

| 片中说法 | 出处 / 性质 |
|---|---|
| 反脚（switch）练习顺序：推坡 → 落叶飘 → 换刃 → 连弯 | 新西兰滑雪教练协会（NZSIA）单板教学手册 *Switch riding* |
| 前 +15°/后 0° 的设置反过来变成前 0°/后 −15°；鸭步 +15°/−15° 正反一样 | 几何推导：换方向后前后脚对调、角度符号相对新板头取反；鸭步是常见的双向设置 |
| 常见错误：身体还朝原方向、重心留在原来的前脚、反脚直接上陡坡 | 教学常见错误（编者整理） |
| 练习与过关 | 教学建议（编者整理），不是文献结论 |
