# 《单板新手课》第6课 · 落叶飘 · 方案

一句话：后刃推坡停稳 → 看板头那边、压前脚往前飘 → 回中停 → 看另一边、压后脚往回飘。

## 片中说法 ↔ 出处

| 片中说法 | 出处 / 性质 |
|---|---|
| 推坡基础上压前脚 / 后脚，板往那一侧飘 | 新西兰滑雪教练协会（NZSIA）单板教学手册 *Falling leaf* |
| 板头偏 10° 顺着板的下滑力约 17%，20° 约 34%，45° 约 71%，90° 为 100% | **示意计算**：顺着板长方向的份额 = sin(偏角)；只说明“偏一点点就够” |
| 常见错误：压前脚太多、只扭上身、低头看板 | 教学常见错误（编者整理）；动作参考《单板从0到刻滑》第5课 |
| 练习与过关 | 教学建议（编者整理），不是文献结论 |
