# 单板新手课 · 配音文稿

不配音出片，字幕按阅读速度排时间（约每秒 5 个字）。每句前面是它在成片里出现的时间（分:秒），2D 版和 3D 版时间完全一样（第2课起只出 2D 版）。**加粗**=重读，⏸=停顿。新的放在最上面。

## 第5课《前刃推坡》（0:59）

- `0:00` 会了后刃，**换个方向**也要能停。
- `0:03` 第二个刹车：**前刃推坡**。
- `0:06` 第一，面朝**山上**，膝盖往前顶，**脚跟抬起**。
- `0:11` 第二，前刃卡住雪就停住，**上身直立**别弯腰。
- `0:15` 第三，脚跟**慢慢放低**，板开始往下溜。
- `0:19` 第四，想停：**脚跟再抬起**，膝盖往前顶。
- `0:23` 前刃也一样：**立刃角**大过坡度就停。
- `0:27` 踮脚尖，脚踝能动约**50°**；
- `0:30` 勾脚尖只有约**20°**，所以前刃通常**更好控制**。
- `0:36` **弯腰撅屁股**：前刃一松，往后栽。
- `0:40` **只踮脚、腿不弯**：一颠就站不稳。
- `0:43` **一只脚用力**：板头往下转。
- `0:47` 练习：面朝山上，滑一米**停一下**，连续10次。
- `0:52` 过关：想停就停，**上身一直直立**。
- `0:56` 下一课：**落叶飘**。

## 第4课《后刃推坡》（0:59）

- `0:00` 站在坡上**停不住**，越滑越快？
- `0:03` 第一个刹车：**后刃推坡**。
- `0:06` 第一，面朝下坡，**屈膝坐低**，像要坐椅子。
- `0:10` 第二，**脚尖勾起**，后刃卡住雪，人就停住。
- `0:15` 第三，脚尖**慢慢放低**，板开始往下溜。
- `0:19` 第四，两脚**平均用力**，板横着，直直往下。
- `0:24` 停还是滑，看**立刃角**和**坡度**谁大。
- `0:27` 立刃比坡度**大**：刃卡进雪，停住；
- `0:31` 比坡度**小**：往下溜；完全放平，**前刃一碰雪就摔**。
- `0:37` **板放平**：前刃挂雪，往前摔。
- `0:40` **直腿站**：一颠就失去平衡。
- `0:43` **只压一只脚**：板头往下转，越滑越歪。
- `0:48` 练习：滑一米，**停一下**，连续10次。
- `0:52` 过关：**想停就停**，板一直横着。
- `0:56` 下一课：**前刃推坡**。

## 第3课《直滑降》（0:59）

- `0:00` 第一次**从坡上滑下来**。
- `0:02` 不转弯、不刹车，先学会**直直地滑**。
- `0:07` 第一，选**很缓的坡**，坡底要有**平地**。
- `0:10` 第二，基本站姿，重心在**两脚中间**。
- `0:14` 第三，板**放平**，板头朝**正下方**。
- `0:17` 第四，眼睛**看前方**，到平地自然停下。
- `0:21` 为什么坡底一定要有平地？
- `0:24` 直滑降不刹车，**速度会一直涨**。
- `0:28` 8°缓坡：滑5米约**11 km/h**，滑20米就到**21 km/h**。
- `0:35` **重心在后脚**：板一转，人往后坐。
- `0:39` **怕快往后仰**：越仰越控制不住。
- `0:43` **低头看板头**：方向慢慢跑偏。
- `0:46` 练习：缓坡上滑**5米**，到平地停下，重复。
- `0:51` 过关：连续**5次**板头朝下，不转不摔。
- `0:55` 下一课：**后刃推坡**，学会刹车。

## 第2课《单脚蹬行》（0:57）

- `0:00` 单板在平地上，**怎么往前走**？
- `0:03` 排队、下缆车，全靠**单脚蹬行**。
- `0:07` 第一，前脚**绑好**，后脚**解开**。
- `0:10` 第二，肩膀和视线，**转向板头**。
- `0:13` 第三，后脚放在**前刃一侧**，贴着板小步蹬。
- `0:17` 第四，滑起来后，后脚**踩上止滑垫**。
- `0:22` 为什么要**顺着板**蹬？
- `0:24` 顺着板蹬，力**全部**往前；
- `0:27` 斜着45°蹬，只剩**约七成**往前，另一部分在推板**打转**。
- `0:34` **后脚跑到板尾后面**：板绕前脚转圈。
- `0:37` **步子太大**：脚伸太远，人跟着晃。
- `0:41` **身体侧着、低头**：越蹬越歪。
- `0:45` 练习：平地上**蹬三步，滑一段**。
- `0:48` 过关：蹬**20米**不打转，踩上板能滑**2~3米**。
- `0:54` 下一课：**直滑降**。

## 第1课《基本站姿》（1:05）

- `0:00` 单板第一课：先学会**站**。
- `0:03` 站不对，⏸ 后面每课都在**摔**。
- `0:06` 先调固定器：两脚距离**约等于肩宽**。
- `0:10` 角度：前脚**正15度**，后脚**0到负6度**，⏸ 微微外八。
- `0:16` 第一，脚踝膝盖**一起弯**，膝盖对脚尖。
- `0:20` 第二，重心在**两脚中间**，略偏前脚。
- `0:23` 第三，上身**直立**，手臂放松张开。
- `0:27` 第四，眼睛**看前方**，别盯脚下。
- `0:30` 雪面从来不平，⏸ 腿就是**减震器**。
- `0:34` 过10厘米小坎：直腿只缓冲2厘米，冲击约**6倍体重**；
- `0:39` 屈膝能缓冲10厘米，只有约**2倍体重**。
- `0:44` **直腿站**：一颠就弹起来。
- `0:47` **撅屁股**：重心跑到后脚。
- `0:50` **低头看板**：越滑越僵。
- `0:53` 练习：平地绑好双脚，**蹲起10次**、**小跳5次**。
- `0:58` 过关：落地不晃，膝盖**始终弯着**。
- `1:02` 下一课：**单脚蹬行**。
