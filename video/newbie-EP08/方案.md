# 《单板新手课》第8课 · 连续S弯 · 方案

一句话：弯和弯之间横切一小段，眼睛先看下一个弯，过下坡线换刃、起身轻一点，新刃把弯走完整再接下一个。

## 片中说法 ↔ 出处

| 片中说法 | 出处 / 性质 |
|---|---|
| 连续换刃的节奏：横切 → 看下一个弯 → 换刃 → 走完整 | 新西兰滑雪教练协会（NZSIA）单板教学手册 *Linked turns*；《单板从0到刻滑》第8课 |
| 弯尾板头离下坡线 90° 时下滑力顺着板约 0%，60° 约 50%，30° 约 87% | **示意计算**：份额 ≈ cos(离下坡线的角度) |
| 常见错误：换刃后坐、只转上身不压刃、横切太长 | 教学常见错误（编者整理） |
| 练习与过关 | 教学建议（编者整理），不是文献结论 |
