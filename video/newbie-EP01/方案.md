# 《单板新手课》第1课 · 基本站姿 · 方案

一句话：站姿就是“两脚约肩宽、前脚约 +15°、后脚 0~−6°；脚踝膝盖一起弯、重心居中略偏前脚、上身直、看前方”，膝盖是减震器。

## 片中说法 ↔ 出处

| 片中说法 | 出处 / 性质 |
|---|---|
| 站距约等于肩宽（或稍宽） | Burton 官方博客 *Goofy vs Regular*：建议从比肩稍宽开始；多家教学文章写“与肩同宽” |
| 入门角度：前脚 +15° 左右，后脚 0° 到 −6° | 通用入门设置，雪具商和教学网站的常见写法（+15/0 是“经典起步模板”；也有 +12/−9 的写法）。不是统一标准，片中说“以后按习惯调” |
| 脚踝、膝盖弯曲，膝盖对准脚尖 | 新西兰滑雪教练协会（NZSIA）单板教学手册 *Basic stance*，及 REI 等教学文章 |
| 重心居中，略偏前脚 | 同上（“weight centered, slightly favoring the front foot”） |
| 上身直立、手臂放松、看前进方向 | 同上 |
| 过 10 cm 小坎：直腿冲击约 6 倍体重，屈膝约 2 倍体重 | **示意计算**（简化模型）：匀减速时 冲击 / 体重 ≈ 1 + 坎高 / 缓冲距离。直腿缓冲距离取 2 cm、屈膝取 10 cm 都是示意值，不是实测 |
| 重心分配 50/50 → 略偏前脚 | 示意（教学口诀的可视化），画面上标了“示意” |
| 练习：蹲起 10 次、小跳 5 次；过关标准 | 教学建议（编者整理），不是文献结论 |

## 结构（65 秒，竖屏，不配音）

| 段落 | 时间 | 画面 |
|---|---|---|
| 开头 | 0–6 s | 实拍航拍 + 大字“单板第1课 基本站姿”+“站不对 = 一直摔”印章 |
| 先调固定器 | 6–16 s | 俯视人物 + 俯视示意图（站距、角度动画） |
| 四个要领 | 16–30 s | 人物从直腿慢慢摆成正确站姿；顶部分步条；膝盖圈、重心分配条、躯干线、视线箭头 |
| 为什么要屈膝 | 30–44 s | 实拍雪坡 → 人物直腿过坎 / 屈膝过坎 + 冲击柱状图 |
| 三个错误 | 44–53 s | 直腿、撅屁股、低头，红圈标出问题，最后回到正确站姿 |
| 练习 | 53–62 s | 蹲起、小跳演示 → 实拍雪场 +“过关”印章 |
| 结尾 | 62–65 s | 实拍缆车 + 下一课预告 |

## 两个版本

- **2D 版**：扁平描边插画，cairo 直接画，人物骨架和 3D 版是同一套（`rig3d.skeleton`），动作、机位完全一致。
- **3D 版**：沿用《单板从0到刻滑》第6课起的白天雪山画风（`rig3d_day.py`，Blender Cycles，640×1138 渲染后放大到 1080×1920）。

## 已知局限

- 实拍只有环境镜头，没有单板近景（见素材清单）。
- 3D 人物的固定器是 0° 摆放，没有真的转到 +15° / −6°；角度靠俯视示意图说明。
- 冲击倍数是简化模型，只用来说明“屈膝能把冲击降几倍”这个量级。
