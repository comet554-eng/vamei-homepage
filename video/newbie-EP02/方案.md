# 《单板新手课》第2课 · 单脚蹬行 · 方案

一句话：前脚绑好、后脚解开；肩和视线转向板头；后脚在前刃一侧贴着板小步蹬；滑起来后后脚踩止滑垫。

## 片中说法 ↔ 出处

| 片中说法 | 出处 / 性质 |
|---|---|
| 前脚绑好、后脚解开，后脚在前刃（脚尖）一侧蹬 | 新西兰滑雪教练协会（NZSIA）单板教学手册 *Skating*；也是各雪场新手课的通用做法 |
| 肩膀、视线转向板头；小步蹬；滑行时后脚踩在止滑垫上 | 同上 |
| 后脚跑到板尾后面蹬，板会绕前脚打转 | 教学常见错误；《单板从0到刻滑》第3课用过同一个演示 |
| 顺着板蹬力 100% 往前；偏 20° 剩约 94%，偏 45° 剩约 71% | **示意计算**：力的分解，往前分力 = 蹬力 × cos(偏角)，侧向分力 = 蹬力 × sin(偏角)；只说明方向的影响，不是实测 |
| 练习：蹬三步滑一段；过关：蹬 20 米不打转、踩上板滑 2~3 米 | 教学建议（编者整理），不是文献结论 |
