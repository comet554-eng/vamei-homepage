# 滑雪科普短片

完整规范见同目录 `原始提示词.md`（用户原版，必须遵守），叙事方案的写法照 `范例-板子为什么会自己转弯.md`。本文件只补充在这个仓库、这个云端环境里的做法；与 `CLAUDE.md` 冲突时以 `CLAUDE.md` 为准。

## 流程

1. **核实资料**：只用一手来源（论文、官方规则、教材）。片中每一句说法都要进"片中说法 ↔ 出处"对照表；只看到摘要的，只引用摘要里写明的结论；查不到的作者、卷号不要编。
2. **叙事方案** 存为 `video/ski-sci-EPxx-方案.md`，内容：一句话知识点、对照表、python 算出来的例子（数字不心算）、分段结构与时长、已知局限、未能核实的内容。然后**停下等用户确认**（用户说"你自己来"才跳过）。
3. **制作**：源码放 `video/ski-sci-EPxx/`（`scenes.py`、`render.py`、`music.py`，配音版再加 `script.py`、`tts.py`、`timeline.json`），成片和封面放 `video/`，命名 `滑雪里的物理EPxx-<标题去标点>.mp4`、`…-竖版9x16.jpg` 等。
4. **交付**（按 `CLAUDE.md`）：仓库成片的 raw 下载链接；4 张封面图直接发到对话里；一份发布文案（首选标题+副标题、备选 2 个、视频描述），同时写进 `video/发布文案.md` 最上面；如实说明查了什么、哪些没核实、哪些是示意计算。

## 风格（与原始提示词一致）

- 1920×1080、30 fps、深色底 `#07090C`；主色：雪面冷白 `#E8EEF4`、清晨淡金 `#E9C77B`、冰蓝 `#7FB6E6`、警示红 `#E06A5A`。
- 字幕底部居中，`{b|…}` 蓝、`{w|…}` 金、`{r|…}` 红高亮；左上章节标签（大号数字 + 细线 + 小字，可带比例尺或实时读数）；右上文献卡（期刊/年份、中文结论、作者、"文献"印章）；左下模型说明（"示意 · 简化模型"）。
- 所有曲线、数值由公式实时算出。每句字幕对应一个画面变化，句间约 0.2 s，转场 ≤ 0.4 s。

## 本环境的已知情况

- **网络**：bash 里只能访问 pypi / npm 等包仓库，Europe PMC、arXiv、出版社网站都被拦（403），WebFetch 也解析不了这些域名；**只能用 WebSearch 查文献**，拿到的是检索摘要，所以引用以"摘要/检索到的元数据"为限，并在方案里写明。
- **依赖**：`pip install pycairo` 可用；numpy、PIL、ffmpeg（libx264 + aac）、node 已装。
- **字体**：系统只有文泉驿正黑。fonts.gstatic.com 可访问：用 `curl "https://fonts.googleapis.com/css2?family=Noto+Serif+SC:wght@400;700&family=Noto+Sans+SC:wght@400;700"` 取 ttf 地址，下载到 `~/.fonts` 后 `fc-cache -f`。注意字体族名是 **`Noto Serif SC`**（不是模板里的 `Noto Serif CJK SC`），模板 `common.py` 的 `SERIF`/`SANS` 要改。
- **模板代码**：`templates/` 是上一部（侧切转弯）的完整源码：`common.py`（画布、字幕、标签、文献卡、编码器）、`draw.py`（雪面、轨迹、板）、`ski.py`、`s_*.py`（场景）、`render.py`、`music.py`、`optics.py`（只有蓝闪蝶那部需要，`common.py` 用它算两个颜色，可换成常量）。`render.py` 里 still 输出路径写死为 `/sessions/...`，要改。
- **渲染**：这里不限 3 分钟，但仍按 300 帧一段分块渲染（便于重跑），最后 ffmpeg concat 并核对帧数。
- **配音**：edge-tts（微软）和 huggingface 都被拦，但 npm 包 `expo-kokoro` 自带 Kokoro-82M 模型和 8 个中文音色（云希/云健/云扬/云夏/晓晓/晓伊/晓北/晓妮）。`video/ski-data-lib/setup_tts.sh` 装好后用 `voice.py list` → `tts.py` → `build.sh`，字幕时间自动跟配音对齐（见 README「单板 · 用数据说话」）。语速 0.9 比较自然；年份、多音字（如“长杠杆”）用 `scenes.SAY` 改读法。没有配音时，时间轴按每秒 4.4 字、每个逗号 +0.25 s 估算。
- 成片太大时注意仓库体积：`-crf 17` 的 1080p 三分钟片约 60–150 MB，超过 100 MB GitHub 会拒收，必要时把 crf 调到 20 左右。
