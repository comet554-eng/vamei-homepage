# VAMEI 小黑板 154 · 板面设计

- `board.js`：154 板型轮廓（1:1 毫米），来自 VAMEI 5.0-154 板型图。`node board.js` 生成 `template.svg`。
- `concepts/*.js`：每款板面的生成脚本，`node concepts/<名>.js` 输出同名 SVG。
- `render.js`：SVG → PNG 预览；`sheet.js`：六款拼成 `png/对比图.png`。

| 编号 | 名字 | 一句话 |
|---|---|---|
| A | 值日黑板 | 板子就是教室黑板，角上「值日生」框写名字、第一次上雪日期、雪场 |
| B | 量角器 | 固定器位置印角度、站距刻度，装固定器照着调 |
| C | 留白点阵 | 亮油隐形点阵对齐贴纸，四角裁切线，朱红「留白」印 |
| D | 贴纸位 · 雪场护照 | 12 个虚线贴纸位，按雪场攒限定贴 |
| E | 等高线 | 板头板尾两座山的亮油等高线，中间留白 |
| F | 第一道线 | 一道刻滑轨迹，弯顶粗、换刃处细 |

## 生产前要做的

- VAMEI 字样现在是 Inter 占位字体，换成官方 logo；所有文字转曲。
- 孔位只是示意，生产文件里删掉。
- 默认工艺：哑光黑底 + 一层局部亮油（深灰示意）+ 最多两个专色（暖白、朱红/橙）。细线不低于 0.6mm、文字字高不低于 4mm，打样确认。
- 固定器底盘大约盖住两侧 ±150～±390mm 的区域，B 款的刻度只在装固定器时看得到，A、C、D 的信息都放在了不被挡住的位置。
- 板面图案定稿后、公开之前申请外观设计，贴纸图案做著作权登记。
