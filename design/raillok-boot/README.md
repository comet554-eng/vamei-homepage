# RAILLOK 单板雪鞋 · 款式提案

## 提案 03「一线」（当前方案）

- `RAILLOK雪鞋款式提案03_一线.pdf`：2 页。第 1 页主推款（曜黑）大图、标注和设计原则，第 2 页四套同色配色和三处细节。
- 预览：`RAILLOK雪鞋款式提案03_一线-1.png` / `-2.png`。

一色、一体、一线：整只鞋一个颜色，不拼色；层次全靠材质（磨砂鞋面、模压包头和后跟杯、软垫内胆领口、
金属旋钮圈）和光影；鞋面上只雕一条腰线，从脚背收进旋钮（RAIL 引向 LOK）；标志只做同色压印。

配色：曜黑（主推）、岩灰、鼠尾草、骨白，色值在 `tools/render3.py` 的 `COLORWAYS`。

渲染方式：`tools/render3.py` 不画平面色块，而是给每个部件算高度图（倒角、软垫鼓起、缝线凹槽、压印、
腰线折痕），再按主光 + 轮廓光 + 柔光箱算明暗、高光和自阴影，输出透明底 png。
重新生成：`npm i && ./build3.sh`（主图渲染较慢，约 6 分钟）。

## 提案 02「壳与芯」（已否：大块撞色拼接显得廉价）

- `RAILLOK雪鞋款式提案02_壳与芯.pdf`：2 页。第 1 页主推配色大图、标注和设计概念，第 2 页四套配色和三处细节。
- 预览：`RAILLOK雪鞋款式提案02_壳与芯-1.png` / `-2.png`。

标志是「一个外框里套着一个形」，鞋也拆成两层：
外面一层硬壳，从鞋头包到后跟，再沿后背往上收成脊条（一个 L），和同色的鞋带盖一起三面围住；
里面一层软芯，绗缝顺着壳的边一圈圈往外走（等高线）。壳的上沿压一道鼠尾草绿细线。
标志只缩小放在后跟旋钮盖上，并压印在后背脊条上，不再整个贴在鞋上。

配色：曜黑 / 骨白（主推）、岩灰 / 骨白、鼠尾草 / 骨白、全黑，色值在 `tools/boot2.py` 的 `COLORWAYS`。

重新生成：`npm i && ./build2.sh`。`tools/boot2.py` 画鞋（`UPPER` 鞋面轮廓、`HERO` 壳的上沿、
`QC` 绗缝间距、`DIAL` 旋钮位置），`tools/sheet2.py` 排版和标注，`tools/crops.py` 裁细节图。

## 提案 01（已否：标志整个套在鞋上，太直白）

- `RAILLOK雪鞋款式提案01.pdf`：2 页矢量 PDF。第 1 页是主推配色大图、部件标注和设计说明，第 2 页是四套配色。
- `RAILLOK雪鞋款式提案01-1.png` / `-2.png`：预览图。
- `src/RAILLOK_LOGO规范.pdf`：品牌标志规范（图形标、字标、品牌色都从这里取）。

## 设计思路

从侧面看，鞋本身就是 RAILLOK 的标志：标志外框围住鞋筒，做成后跟杯、后背支撑和领口；
里面那一笔折线做成锁跟带，从脚背斜拉到后跟；标志末端的小方块放第二个旋钮，专门调锁跟带。
鞋头朝右画（右脚外侧），这样标志是正的；左脚外侧和每只鞋的内侧是镜像。

大底、中底、内胆领口、提拉环和上区旋钮沿用 Vamei 双扣 TP 稿的形状（`../vamei-boot/src/`），
鞋面是新画的。

## 配色

只用品牌四色：骨白 #F3F2EE、黑 #000、鼠尾草绿 #C2D8C5、岩灰 #68747A。
四套：岩灰 SLATE（主推）、骨白 BONE、鼠尾草 SAGE、曜黑 BLACK，变量在 `tools/boot.css`。

## 重新生成

```
npm i          # 排版字体
./build.sh
```

- `tools/pdf2svg.py`：把 PDF 里的每个色块转成 SVG 路径（TP 稿、标志）。
- `tools/boot.py`：拼鞋图。标志框架 = 标志图形按四边形 `QUAD` 贴进鞋筒，`THIN` 控制笔画粗细；
  护片、包头的边线是成品坐标里的几个控制点，改点就能改型。
- `tools/sheet.py`：排版、部件标注（`CALLOUTS`）、说明文字和配色表。
- `tools/pdf.js`：用 Chromium 打印成 PDF。
