# RAILLOK 单板雪鞋 · 款式提案

> 约束：双扣，两个旋钮都是 ATOP 原厂件，旋钮上不能印任何 logo（提案 06 侧旋钮上印了图形标，是错的）。

## 提案 07「一笔」（当前方案）

- `RAILLOK雪鞋款式提案07_一笔.pdf`：3 页矢量 PDF。第 1 页白色款式图 + 10 处编号说明，第 2 页主推石墨 + 色卡，第 3 页四套配色。
- 预览：`RAILLOK雪鞋款式提案07_一笔-1.png` / `-2.png` / `-3.png`。

一条护条一笔画完：鞋头后面沿底边（防泥条）→ 绕过后跟（后跟杯）→ 斜着扫上鞋筒 → 收进侧旋钮底座。
围着护条两圈「回声」（一圈绒面带细孔、一圈双明线），前护片里也有一道顺着后沿的回声缝，整只鞋的线都跟着这一笔走；
脚背弯折处一个斜长圆鞋带窗（网布 + 交叉钢丝），后背脊条两条反光拉片，鞋头一排孔。
两个旋钮按 ATOP 原厂外观画（前旋钮用 TP 原图，侧旋钮是正视图：底座 + 齿圈 + 翼片），不印 logo；
品牌只在鞋面上：护条底边压 RAILLOK 字标、后跟压图形标、鞋舌顶上一个织唛。
阴影改成 TP 那种柔和的喷枪灰（模糊），不再用硬投影；配色都是同一色系深浅 + 一道滚边。

分片和配色在 `tools/rail7.py`（`MUD` / `RISE` 护条、`CAGE` 前护片、`COLORWAYS`），排版 `tools/sheet7.py`。
重新生成：`npm i && ./build7.sh`。

## 提案 05：四个方向

- `RAILLOK雪鞋款式提案05_四个方向.pdf`：5 页。第 1 页四款配色版总览，第 2–5 页每个方向一页（白色款式图 + 配色 + 要点）。
- 预览：`RAILLOK雪鞋款式提案05_四个方向-1.png` … `-5.png`。

| 方向 | 设计语言 | 配色 |
|---|---|---|
| A 流线 | 一条大斜带从后领口斜挎到脚背，上下鞋身片顺着它走 | 骨白鞋身 + 岩灰斜带 / 护片，鼠尾草绿细线 |
| B 棱面 | 直线和折角，后跟两片尖楔指向脚踝，六边形网布窗 | 全黑 + 岩灰内楔，鼠尾草绿细条 |
| C 绑带 | 外露的锁跟织带（方框交叉缝锚点、金属扣），上鞋身横向绗缝 | 岩灰鞋身 + 黑色护片 / 后跟，鼠尾草绿织带 |
| D 等高线 | 四层压片像等高线往上叠，越往后跟越高 | 岩灰同色系由深到浅渐变 |

画法共用 `tools/tpkit.py`（照 TP：黑描边、双线明缝、龟裂纹、网布、压片投影，沿用 TP 的大底 / 中底 / 内胆 / BOA / 魔术贴），
各方向的分片和配色在 `tools/variants.py`。重新生成：`npm i && ./build5.sh`。

## 提案 03「一线」（已否：同色一体太素，分片和线条太少）

- `RAILLOK雪鞋款式提案03_一线.pdf`：2 页。第 1 页主推款（曜黑）大图、标注和设计原则，第 2 页四套同色配色和三处细节。
- 预览：`RAILLOK雪鞋款式提案03_一线-1.png` / `-2.png`。

一色、一体、一线：整只鞋一个颜色，不拼色；层次全靠材质（磨砂鞋面、模压包头和后跟杯、软垫内胆领口、
金属旋钮圈）和光影；鞋面上只雕一条腰线，从脚背收进旋钮（RAIL 引向 LOK）；标志只做同色压印。

配色：曜黑（主推）、岩灰、鼠尾草、骨白，色值在 `tools/render3.py` 的 `COLORWAYS`。

渲染方式：`tools/render3.py` 不画平面色块，而是给每个部件算高度图（倒角、软垫鼓起、缝线凹槽、压印、
腰线折痕），再按主光 + 轮廓光 + 柔光箱算明暗、高光和自阴影，输出透明底 png。
重新生成：`npm i && ./build3.sh`（主图渲染较慢，约 6 分钟）。

## 提案 01（已否：标志整个套在鞋上，太直白）

- `RAILLOK雪鞋款式提案01.pdf`：2 页矢量 PDF。第 1 页是主推配色大图、部件标注和设计说明，第 2 页是四套配色。
- `RAILLOK雪鞋款式提案01-1.png` / `-2.png`：预览图。
- `src/RAILLOK_LOGO规范.pdf`：品牌标志规范（图形标、字标、品牌色都从这里取）。

## 设计思路

从侧面看，鞋本身就是 RAILLOK 的标志：标志外框围住鞋筒，做成后跟杯、后背支撑和领口；
里面那一笔折线做成锁跟带，从脚背斜拉到后跟；标志末端的小方块放第二个旋钮，专门调锁跟带。
鞋头朝右画（右脚外侧），这样标志是正的；左脚外侧和每只鞋的内侧是镜像。

大底、中底、内胆领口、提拉环和上区旋钮沿用 Vamei 双扣 TP 稿的形状（`../vamei-boot/src/`），
鞋面是新画的。

## 配色

只用品牌四色：骨白 #F3F2EE、黑 #000、鼠尾草绿 #C2D8C5、岩灰 #68747A。
四套：岩灰 SLATE（主推）、骨白 BONE、鼠尾草 SAGE、曜黑 BLACK，变量在 `tools/boot.css`。

## 重新生成

```
npm i          # 排版字体
./build.sh
```

- `tools/pdf2svg.py`：把 PDF 里的每个色块转成 SVG 路径（TP 稿、标志）。
- `tools/boot.py`：拼鞋图。标志框架 = 标志图形按四边形 `QUAD` 贴进鞋筒，`THIN` 控制笔画粗细；
  护片、包头的边线是成品坐标里的几个控制点，改点就能改型。
- `tools/sheet.py`：排版、部件标注（`CALLOUTS`）、说明文字和配色表。
- `tools/pdf.js`：用 Chromium 打印成 PDF。
