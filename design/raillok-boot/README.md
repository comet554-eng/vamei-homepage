# RAILLOK 单板雪鞋 · 款式提案 01

- `RAILLOK雪鞋款式提案01.pdf`：2 页矢量 PDF。第 1 页是主推配色大图、部件标注和设计说明，第 2 页是四套配色。
- `RAILLOK雪鞋款式提案01-1.png` / `-2.png`：预览图。
- `src/RAILLOK_LOGO规范.pdf`：品牌标志规范（图形标、字标、品牌色都从这里取）。

## 设计思路

从侧面看，鞋本身就是 RAILLOK 的标志：标志外框围住鞋筒，做成后跟杯、后背支撑和领口；
里面那一笔折线做成锁跟带，从脚背斜拉到后跟；标志末端的小方块放第二个旋钮，专门调锁跟带。
鞋头朝右画（右脚外侧），这样标志是正的；左脚外侧和每只鞋的内侧是镜像。

大底、中底、内胆领口、提拉环和上区旋钮沿用 Vamei 双扣 TP 稿的形状（`../vamei-boot/src/`），
鞋面是新画的。

## 配色

只用品牌四色：骨白 #F3F2EE、黑 #000、鼠尾草绿 #C2D8C5、岩灰 #68747A。
四套：岩灰 SLATE（主推）、骨白 BONE、鼠尾草 SAGE、曜黑 BLACK，变量在 `tools/boot.css`。

## 重新生成

```
npm i          # 排版字体
./build.sh
```

- `tools/pdf2svg.py`：把 PDF 里的每个色块转成 SVG 路径（TP 稿、标志）。
- `tools/boot.py`：拼鞋图。标志框架 = 标志图形按四边形 `QUAD` 贴进鞋筒，`THIN` 控制笔画粗细；
  护片、包头的边线是成品坐标里的几个控制点，改点就能改型。
- `tools/sheet.py`：排版、部件标注（`CALLOUTS`）、说明文字和配色表。
- `tools/pdf.js`：用 Chromium 打印成 PDF。
